# Segurança

Encontrou uma falha? Use **Security → Report a vulnerability** neste repositório. O relato é privado.

Não abra uma issue pública para falhas de segurança. Teste só com provas inofensivas e sem afetar outras pessoas.

O site é estático, sem login, sem servidor próprio e sem coleta de dados. As preferências ficam só no navegador.
